# MyFirstWeb 🌐

`MyFirstWeb` adalah sebuah proyek website landing page sederhana yang dirancang dengan estetika modern, responsif, dan interaktif. Proyek ini dibangun menggunakan **HTML5**, **CSS3 (Custom Properties & Flexbox/Grid)**, dan **JavaScript (ES6+)**.

---

## 📁 Struktur Folder

```text
proyek3/
├── css/
│   └── style.css      # Styling utama, variabel warna, mode gelap/terang, dan media queries
├── js/
│   └── main.js        # Logika interaktif (Dark mode toggle, mobile menu, form feedback, counter)
├── index.html         # Halaman utama (Landing page)
└── README.md          # Dokumentasi proyek
```

---

## ✨ Fitur Utama

- **Desain Modern & Minimalis:** Tampilan estetis dengan gradien halus, tipografi Poppins, dan kartu bergaya kaca (glassmorphism/card UI).
- **Responsive Layout:** Sepenuhnya adaptif di berbagai perangkat (Mobile, Tablet, Desktop).
- **Dark & Light Mode:** Tombol pengalih tema (Dark/Light) yang persisten menggunakan `localStorage`.
- **Interaktif:** 
  - Menu navigasi mobile (Hamburger menu).
  - Simulasi statistik pengunjung real-time.
  - Form kontak interaktif dengan notifikasi sukses instan.

---

## 🚀 Cara Menjalankan

1. Clone repository atau unduh file proyek ini.
2. Buka terminal pada direktori proyek.
3. Jalankan file `index.html` menggunakan browser pilihan Anda (atau gunakan Live Server di VS Code).
